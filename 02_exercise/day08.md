# 突破增词与减词语（一）

## 一、请回答下列问题

### 1. 什么是英文的形合与中文的意合？中英文的三大差异是什么？

中文的意合和英文的形合指的是有关**句子之间连接**的问题。

1. 中文的句子一般没有什么连词，主要是通过句子之间的意思来体会相互之间的关系。
2. 英文则是要通过句与句之间的连词来判断句子之间的关系。

中英文的三大差异：

1. **长短差异**：中文善于用短句，且用逗号隔开；英文善于用长句，不用标点。
2. **动静差异**：中文善于用动词，属于动态性语言；英文善于用名词，属于静态性语言。
3. **意形差异**：中文是意合语言，句与句之间的连词比较少；英文是形合语言，句与句之间的连词较多。

### 2. 汉译英的步骤是什么？

1. **断句**（句子的组合）：判断哪些句子应该放在一起翻译，而不是把所有句子都一口气翻译完，然后在每个句子之间加上合适的**连词**。
2. **找谓语**：判断句子当中哪个动词重要，哪个动词不重要。
3. **翻译**：按照顺序来翻译这个句子，一部分一部分有步骤地翻译。
4. **重读**：把这个句子脱离中文，只读英文，让这个句子更加符合英文的习惯。

### 3. 规律四——谓语动词的层次性指的是什么？

一般来说，我们把句子中最重要的动词作为句子的 “核心谓语”，其次重要的是 “非谓语动词或是从句”，再次重要的是 “介词”，最不重要的就 “不翻译”。

### 4. 英译汉时断句的标准是什么？

1. 在原有标点处一定要断句；
2. 在从句处一定要断句；
3. 在介词短语处一定要断句；
4. 主语过长一定要断句，而且要单独翻译。

### 5. 古文应当如何翻译？基本思路是什么？

古文应该使用**解释**的方法来翻译。
